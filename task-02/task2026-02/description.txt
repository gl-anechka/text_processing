Для выделения припевов используется эвристический алгоритм поиска повторяющихся последовательностей строк песни.
Предполагается, что припев содержит не менее двух строк и встречается в тексте несколько раз.

1) Перед сравнением каждая строка песни приводится к единому виду (функция normalize): символы переводятся в нижний 
регистр, буква «ё» заменяется на «е», удаляются знаки препинания и лишние пробелы.

2) Для сравнения строк используется ratio из библиотеки Levenshtein. Результат находится в диапазоне от 0 до 1, 
если хотя бы одна из строк пустая, сходство принимается равным 0.
Для каждой песни строится матрица sim, которая содержит значения попарного сходства всех строк.

3) Алгоритм перебирает возможные длины припева от 2 строк до половины длины песни. Для каждой длины рассматриваются 
все допустимые начальные позиции предполагаемого припева. Выбранный фрагмент используется в качестве образца. 
Далее в оставшейся части песни выполняется поиск похожих фрагментов такой же длины.
Сходство двух фрагментов вычисляется как среднее арифметическое сходства соответствующих строк.
Если полученное сходство не меньше 0.8, фрагмент считается повторением образца. Его начальная позиция добавляется в 
список найденных вхождений. Чтобы исключить наложение повторений друг на друга, при поиске пропускаются фрагменты, 
пересекающиеся с последним выбранным вхождением.

4) Для каждого варианта припева вычисляется суммарная оценка. За каждое найденное повторение начисляются баллы по формуле:
score += size * match ** 7, где size — длина фрагмента в строках, а match — среднее сходство повторения с образцом.
Чем больше длина и количество повторений, тем выше итоговая оценка кандидата.
Баллы начисляются только за дополнительные повторения, без учёта самого образца. Порог сходства и степень подобраны 
экспериментально при провере алгоритма на предложенных примерах.

5) Среди всех рассмотренных кандидатов выбирается вариант с максимальной суммарной оценкой. Для каждого такого вхождения 
формируется пара индексов (start, end).
