## Структура архива:

- features.py --- создание обучающих примеров для модели: токенизация, извлечение признаков
- prepare.py --- подготовка данных для обучения: удаление файлов с разрывными сущностями
- solution.py --- класс Solution с методом predict
- train.py --- обучение модели
- description.txt --- описание решения и инструкция по воспроизведению модели
- model.pkl --- обученная модель и DictVectorizer
